ELENA'S CAFÉ - RESPONSIVE PRODUCT CATALOG

Created by: Yara
Project: Responsive Product Catalog
Date: September 2026


PRODUCT THEME & TARGET AUDIENCE

Elena's Café is a coffee and sweets product catalog designed for
customers who enjoy coffee, refreshing drinks, and sweet treats.

The catalog includes coffee drinks such as espresso, americano,
cappuccino, latte, iced caramel macchiato, Spanish latte, and
matcha latte.

The sweets category includes chocolate chip cookies and
New York cheesecake.

The target audience includes coffee lovers, students, workers,
and customers looking for coffee and sweet treats.


RESPONSIVE BREAKPOINTS

Mobile:
The default layout uses one column for product cards.

Tablet:
At a minimum width of 600px, the coffee products use a
two-column grid.

Desktop:
At a minimum width of 992px, the coffee products use a
three-column grid.


DESIGN DECISIONS

The website uses a warm café-inspired color palette.

Main colors:
- Bright yellow
- Cream
- Dark brown

The yellow color represents the Elena's Café branding.
Cream is used for the page background.
Dark brown is used for text and the footer.

The website uses Georgia for headings and Arial for product
descriptions.

The layout uses CSS Grid to create a responsive product catalog.

Coffee and sweets are separated into two categories to make
the products easier to browse.

Product cards use rounded corners, borders, shadows, and a
small hover effect.


ACCESSIBILITY

Images include descriptive alt text.

Semantic HTML elements such as header, main, section, article,
figure, and footer are used to organize the page.


PRODUCT IMAGES
